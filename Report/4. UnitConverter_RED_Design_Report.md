## STEP 4 — `/red-test-plan` (D-CONV-01~03)

**Phase:** `red` · **Layer:** `entity` · **Track:** Logic  
**RED 묶음:** D-CONV-01 ~ D-CONV-03 (1 파일)

### C2C · Rule 1~3

| Rule | 내용 |
|------|------|
| Rule 1 | PRD 요구 1건 → Test ID ≥ 1건 |
| Rule 2 | Given/Then은 PRD·비즈니스 로직에서 직접 유도 |
| Rule 3 | 모호한 판단은 To-Do에 명시 결정 |

| 항목 | 내용 |
|------|------|
| **PRD** | FR-2 — meter, feet, yard 간 변환을 **meter 기준**으로 계산 |
| **비즈니스 로직** | `1 m = 3.28084 ft` · `1 m = 1.09361 yd` · feet/yard는 meter 경유 |
| **To-Do (판단)** | entity API = `convert_length(value, from_unit, to_unit) -> float` 단일 순수 함수 |
| **SC** | SC1 (즉시·정확 변환), SC3 (테스트로 재확인 불필요) |

### Test ID → Given / When / Then

| Test ID | Given | When | Then |
|---------|-------|------|------|
| D-CONV-01 | G1: `2.5 meter` | `convert_length(2.5, "meter", "feet")` | `8.2021` |
| D-CONV-02 | G1: `2.5 meter` | `convert_length(2.5, "meter", "yard")` | `2.734025` |
| D-CONV-03 | G1: `8.2021 feet` | `convert_length(8.2021, "feet", "yard")` | `2.734025` (meter 경유) |

### G1 변환 격자 (RED SSOT)

```
anchor: 2.5 meter
  ├─ D-CONV-01 → 8.2021 feet    (× 3.28084)
  ├─ D-CONV-02 → 2.734025 yard  (× 1.09361)
  └─ D-CONV-03: 8.2021 feet → 2.734025 yard
```

### Track B RED 설계표

| Test ID | 대상 함수 | Given→Then | Invariant | Expected RED Failure |
|---------|-----------|------------|-----------|----------------------|
| D-CONV-01 | `convert_length()` | G1 meter→feet | I-METER · I-SSOT · I-NO-BND | `ModuleNotFoundError` / `ImportError` |
| D-CONV-02 | `convert_length()` | G1 meter→yard | I-METER · I-SSOT · I-NO-BND | 동일 |
| D-CONV-03 | `convert_length()` | G1 feet→yard | I-METER · I-CHAIN · I-NO-BND | 동일 |
