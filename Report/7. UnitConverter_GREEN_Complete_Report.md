## STEP 4 — convert_all 의미 정리

| API | 의미 | G1 (`meter:2.5`) 기대 |
|-----|------|------------------------|
| `convert_all()` | 등록된 **전** 단위 (입력 단위 포함) | `{meter: 2.5, feet: 8.2021, yard: 2.734025}` |
| `convert_excluding_input()` | 입력 단위 **제외** | `{feet: 8.2021, yard: 2.734025}` |
| `run_conversion()` / CLI | boundary용 — 입력 단위 제외 (PRD FR-3) | feet·yard 출력만 |

**변경:** GREEN 초기에는 두 API가 동일 구현이었음 → REFACTOR 전 `_convert_to_all_units` / `_convert_excluding_input` 분리.
