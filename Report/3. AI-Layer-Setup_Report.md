## 3. 아키텍처 · TDD 정책 요약

### ECB

```
boundary → control → entity (단방향)
```

- `entity`: 상위 import 금지
- `control`: `entity`만 import
- `boundary`: `control`만 호출, `entity` 직접 호출 금지
- `UnitConverter.py`: boundary thin wrapper (향후 `src/boundary`로 위임)

### Dual-Track

| Track | 위치 | Mock |
|-------|------|------|
| Logic `D-*` | `tests/entity`, `tests/control` | 금지 |
| UI `U-*` | `tests/boundary` | control·I/O만 허용 |

### TDD 게이트

- RED → GREEN → REFACTOR, 구현 순서 entity → control → boundary
- Layer: `pytest tests/<layer> -q` / 전체: `pytest -q`
