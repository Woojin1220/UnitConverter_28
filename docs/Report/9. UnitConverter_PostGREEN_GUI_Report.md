## STEP 5 — PyQt GUI (boundary)

| 산출물 | 경로 | 역할 |
|--------|------|------|
| GUI 앱 | `src/boundary/qt_app.py` | PyQt6 `MainWindow` — 값·단위 입력 → 결과 표시 |
| 진입점 | `UnitConverterGUI.py` | `python UnitConverterGUI.py` |
| control API | `supported_units()` | 등록 단위 목록 (combo box) |

**ECB 준수**

- GUI → `boundary/cli.process()` → `control.run_conversion()` → entity
- entity 직접 import 없음 (단위 목록은 control `supported_units()` 경유)

**실행**

```bash
venv\Scripts\activate
pip install -r requirements.txt
python UnitConverterGUI.py
```
