| Turn | 멘토 | 답변 |

### Mom Test 종료 요약

**표면 문제:** "주어진 값을 원하는 유닛 단위로 바꿔주는 프로그램을 만든다."

**진짜 문제:** 외울 수 없는 다양한 단위 조합 앞에서, 매번 찾아보느라 바로 답하지 못하고 과제가 지연된다.

**증거 3줄:**
1. "공식을 사실 왜우고 다니지는 않아서, ft에서 m로 유닛을 바꾸는 방법을 찾아서 바꿨어"
2. "새로운 단위를 물어볼때마다 찾아봐야한다는 점이 불편했어"
3. "과제지연"

## Part 3. 워크북 작성

**사용자 요청:** Mom Test 결과 기반 워크북 작성

### 입력
- 페르소나: 코딩 수업·과제 학습자
- 진짜 문제: 외울 수 없는 단위 조합 → 매번 찾기 → 과제 지연
- 증거 3줄 (위 인용)

### 산출물

**1) 주제 한 문장**
> 앞으로 어떤 단위 조합이 나올지 모르는 과제에서, 매번 검색·재확인 없이 변환 결과를 바로 얻어 제출 흐름이 끊기지 않게 한다.

**2) R-G-I-O**
| | 내용 |
|---|------|
| Role | `단위:값` → 나머지 모든 단위 변환 담당 |
| Goal | 한 번 입력으로 정확한 전체 변환 결과 즉시 확인 |
| Input | `meter:2.5` 등 |
| Output | 입력 단위 제외 전 단위 변환 목록 |

**3) 성공 기준**
- SC1: 한 번 입력 → 전 단위 즉시 출력 (증거 ①)
- SC2: 새 단위 추가 시 기존 코드 최소 변경 (증거 ②)
- SC3: 테스트 통과 → 재확인 불필요 (증거 ③)

**4) 하지 않을 것**
- UI·검색 우선, 암기 전제, 부가 기능 우선, 미검증 가설 확장

**8계층 (이번 세션):** Rule / Command / Skill / Test Loop
