## Part 1. 8계층 개념 정리 (Ask)

**사용자 요청:** 현재 프로젝트에서 8계층 + Hook이 각각 무슨 역할인지 한 줄씩 설명. `.cursorrules`, Skill, Command, `hooks.json`은 아직 없다고 가정.

**Agent 응답 요약:**

| 계층 | 한 줄 역할 |
|------|-----------|
| Model | PRD·코드 이해, 설계·테스트 생성 (LLM 본체) |
| Agent | TDD 목표를 받아 파일 수정·pytest 반복 실행 |
| Harness | Cursor가 컨텍스트·도구·모드를 감싸 전달하는 런타임 |
| Rule | 항상 지켜야 할 프로젝트 규칙 (`.cursorrules`) |
| Skill | TDD Red→Green→Refactor 등 상황별 절차서 |
| Command | `pytest`, `python UnitConverter.py` 등 표준 명령 |
| Tool/MCP | Read/Shell/pytest, Context7·GitHub MCP |
| Test/Review Loop | RED→GREEN→REFACTOR, SC1~3 검증 |
| Hook | 이벤트 기반 자동화 (pytest, 스냅샷 차단 등) |

**당시 프로젝트 상태:** PRD에 Rule/Command/Skill/Loop 문서만 있고, `.cursor/` 인프라 없음.

## Part 11. 마무리 점검 (Ask)

**사용자 요청:** 코드 수정 없이 8계층+Hook 체크리스트, 계층 간 권고 1가지.

**판정 요약:**

- Rule·Skill·Hook(sessionStart): ✅
- Harness: ❌ (`src/`·`tests/` 당시 누락)
- Command: ⚠️ (2개만)
- Test/Review Loop: ⚠️ (TC 없음, Hook 3종 미구현)

**권고:** Hook에 `afterFileEdit`/`stop`/`beforeShellExecution` 추가 + Harness 복구.
